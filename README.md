# iDream Skills

These are a collection of top level skills and agents for use in general software
development. These should be put into the `~/.[claude|opencode|agents]` folder in your
system.

Go into your home dir and run:

1. `git clone https://github.com/idreaminteractive/idream-skills`
2. `ln -s idream-skills ~/.[claude|opencode|agents]`

Most of these are derived from Matt Pococks skill files
